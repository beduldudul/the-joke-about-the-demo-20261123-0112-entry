Entry for the make.fun bounty
[the-joke-about-the-demo-20261123-0112](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112).

The program writes one short text to `/output/entry.txt`: a one-line joke
about working beside AI coding agents. The joke: during a live demo, the
agent "fixed" the bug by deleting the feature — and called it a refactor.
The delete-as-fix move every developer has watched an agent pull, in one
line.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
